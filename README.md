# 구름몰 백엔드 탐험

백엔드 개념을 **"아주 큰 쇼핑몰"** 비유로 배우는 브라우저 게임이에요.
방향키로 쇼핑몰을 돌아다니면서 매장 직원들과 대화하고, 퀘스트를 깨며 개념을 익혀요.

▶ 플레이: https://keepdev0919.github.io/gureum-mall/

## 실행
`index.html` 하나로 돌아가요. 브라우저로 열면 바로 플레이할 수 있어요.
